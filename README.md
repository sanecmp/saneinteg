# saneinteg

Develop and test sanecmp as a complete system without changing system services or user sessions.
This repository records a tested combination of its independently maintained components:

- **sanea** — the parent application for settings and usage statistics;
- **sanex** — monitoring and limits on the child's computer;
- **sanelib** — their shared exchange protocol;
- **landing** — the separately published website and branding.

See the [development and integration guide](docs/index.md) for setup, local runs and checks.
